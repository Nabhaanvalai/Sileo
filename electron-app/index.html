AI Cleanup

Post-processing
Remove filler words and fix grammar
Adapt tone to app

Edit Mode
Select text, then dictate an instruction to transform it
Developer mode

Custom System Prompt optional

Set only if your Whisper endpoint differs from the LLM endpoint.

Run at Windows startup

These words are passed to Whisper as a spelling guide — improves single-word accuracy and proper noun spelling.
